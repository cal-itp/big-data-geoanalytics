# 2026 Caltrans Climate Change Vulnerability and Risk Assessment (CCVRA)

The 2026 Caltrans Climate Change Vulnerability and Risk Assessment is a statewide planning-level analysis of climate change impacts on Caltrans assets on and along the State Highway System (SHS). This assessment includes climate hazard exposure indicators, risk components and risk ratings for Caltrans assets such as State Highway System roadways, bridges, tunnels, and culverts, using 10th mile segments. Hazard types include Coastal Flooding, Riverine Flooding, Coastal Erosion, Landslide and Wildfire. 

This folder contains the documentation for the 2026 Caltrans CCVRA webmap, including data documentation, color schemes and other relevant infomation. The 2026 CCVRA Report and Technical Report can be found on Caltrans Planning [add_hyperlink]().
